# Bowling Night

Mobile-friendly bowling score and card-game tracker backed by the existing **Bowling Bracket** Supabase project.

## Pages / views
- **Scores** — American League 2026 weekly scratch scores, series, average and points.
- **Card Game** — Assassinations, Self Inflictions, Games Won and Whammies for Brandon, Chad, Chris, Dave, Scott and Guest, plus season leaders.

## Hosting
This repository is designed to be served directly with GitHub Pages from the repository root on the `main` branch.

The browser uses the project's public/publishable Supabase key. Row Level Security is enabled on the bowling tables.
